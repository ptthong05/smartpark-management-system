# FEATURE ROADMAP - SMARTPARK

## 1. Phiên bản MVP 1.0 (Phạm vi hiện tại theo SRS)
- [x] Nhận diện biển số cổng vào & cổng ra bằng AI.
- [x] Phân bổ ô đỗ thủ công bởi nhân viên trên giao diện web (không có app tài xế).
- [x] Camera tầng hầm phát hiện xe đỗ và cập nhật trạng thái `OCCUPIED`.
- [x] Tính phí đỗ xe tự động theo thời gian thực (20k giờ đầu, 10k giờ sau).
- [x] Quản lý thanh toán tiền mặt / QR mô phỏng và điều khiển mở barrier.
- [x] Quản trị bãi xe, ô đỗ, camera, nhân viên và bảng giá dành cho Admin.
- [x] Báo cáo thống kê lượt xe và doanh thu bãi đỗ.

## 2. Phiên bản 2.0 (Mở rộng tương lai)
- [ ] Tích hợp Barrier phần cứng thật qua giao tiếp Serial / GPIO / Relay.
- [ ] Cổng thanh toán trực tuyến tự động qua mã QR động (VietQR / MoMo / VNPay).
- [ ] Cảm biến siêu âm / IoT gắn từng vị trí đỗ bổ trợ cho camera.
- [ ] Quản lý chuỗi nhiều bãi đỗ xe liên kết (Multi-parking network).
- [ ] Ứng dụng di động dành cho tài xế xem ô trống và thanh toán từ xa.
